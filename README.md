# 🚀 Mobile Space Battle Game

**Mobile Space Battle Game** is a mobile game developed using **Python**, **Kivy**, and **KivyMD**.

The project demonstrates how to build a mobile game using Python and modern UI components.

## 🛠️ Technologies Used

- 🐍 **Python** — Main programming language
- 📱 **Kivy** — Framework for developing cross-platform applications
- 🎨 **KivyMD** — Material Design components for Kivy

## 📦 Installation

Follow the steps below to install and run the project.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/mobile_spacebattle_game.git
```

Navigate to the project directory:

```bash
cd mobile_spacebattle_game
```

### 2. Create a Virtual Environment

First, create a virtual environment to manage project dependencies.

```bash
python -m venv .venv
```

### 3. Activate the Virtual Environment

**For Windows:**

```bash
.venv\Scripts\activate
```

**For Linux / macOS:**

```bash
source .venv/bin/activate
```

### 4. Install Dependencies

Install the required Python libraries:

```bash
pip install kivy kivymd
```

### 5. Run the Game

Once all dependencies are installed, start the application:

```bash
python main.py
```

🎉 **Congratulations!** Your game is ready to launch!
